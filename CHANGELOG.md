## [1.4.0] - 2026-07-26

- [Added] - DLNA icon in Add Storage.
- [Added] - IBM Plex Mono font for the code editor and hex viewer.
- [Removed] - Bundled default fonts (FiraCode, JetBrainsMono, Lato, OpenSans); the main font now uses fonts already available on the system.

## [1.3.1] - 2024-04-08

- [Added] - Colors `text_grid_tertiary` and `text_grid_tertiary_inverse` for MiXplorer v6.65+ ([#12](https://github.com/dracula/mixplorer/issues/12)).

## [1.3.0] - 2023-09-03

- [Added] - Purple accent color.
- [Added] - Filled bookmark icons.
- [Fixed] - Oversized button icons.

## [1.2.0] - 2023-07-22

- [Added] - Dracula logo in skin settings.
- [Added] - Shuffle icon in sort menu (_v6.60+_).
- [Added] - Empty-folder icon.
- [Added] - Instagram, Telegram, Twitter, WhatsApp, and Viber icons in bookmarks ([#10](https://github.com/dracula/mixplorer/issues/10)).
- [Added] - Monochrome icon option for bookmarks ([#9](https://github.com/dracula/mixplorer/issues/9)).
- [Removed] - Hubic Drive and Amazon Cloud Drive icons from Add Storage; they rendered incorrectly on MiXplorer v6.60+.

## [1.1.0] - 2022-04-04

- [Fixed] - Selection highlight color in code editor ([#4](https://github.com/dracula/mixplorer/issues/4#issuecomment-968925140)).
- [Improved] - Fixed FTP and HTTP/WebDAV tile icons in the curtain menu, thanks to [@Pushkin31](https://github.com/Pushkin31) ([#4](https://github.com/dracula/mixplorer/issues/4#issuecomment-952234665)).

## [1.0.0] - 2021-10-22

- [Added] - Initial release.
